# リバトレ — 負けるほど、強くなる。

GitHub Pagesで公開する、対局と復習ができるリバーシ学習ゲーム。

## 公開手順

1. GitHubで新しい公開リポジトリ（例: `ribatore`）を作成。
2. このフォルダの **ファイルを直接** リポジトリの最上位にアップロード（ZIPそのものはアップロードしない）。
3. リポジトリの `Settings` → `Pages` で `Deploy from a branch`、`main`、`/(root)` を選び保存。
4. 公開URL（例: `https://ユーザー名.github.io/ribatore/`）をスマホで開き、Chromeの「ホーム画面に追加」または「アプリをインストール」を選択。

## 内容

- CPU対戦（3段階） / 1台で2人対戦
- 8つの基礎レッスン・8問の「次の一手」
- 対局後の敗因分析・盤面での手順比較・打ち直し
- オフライン対応（公開後に初回読込した端末）
- 学習進捗と設定はブラウザのローカルストレージに保存。以前のリバーシ版で記録した学習進捗も同じURL上なら引き継ぐ。

## 注意

- 対局分析は簡易評価による候補提示で、最善手を保証しません。
- 現在の2人対戦は1台を交互に操作する方式で、ネット越しの対戦はありません。
- ブラウザのサイトデータを削除したり、公開URLを変更したりすると、保存した進捗を参照できなくなることがあります。
- GitHub Pages（Public）はソースコードが公開されます。
